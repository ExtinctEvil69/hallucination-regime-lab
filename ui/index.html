Hidden Markov chain · built live

play a conversation to build the chain

The model's hidden state at each turn is G grounded, U uncertain or H hallucinating. It is never observed directly. Each turn, the question's covariates set the transition probabilities A(c), the previous belief is pushed through them to give a prior, and the answer's features act as evidence (emission likelihood) that turns the prior into the posterior belief. The guard holds an answer when the posterior P(H) is high.

Clinical guard on 50 held-out charts

Chart + question→ Pre-answer covariates→ Forecast P(H next)→ Optional re-ground→ Qwen answers→ Features→ Filter P(H | answers so far)→ Hold or commit
1

Read the question, not the answer

Before Qwen replies, the guard looks only at the visible chart. Is the requested row there (evidence)? How many patients match the name (ambiguity)? Are there look-alike codes (distractors)? Which turn is it?

2

Forecast the next answer

A covariate-dependent hidden Markov model turns those facts into transition probabilities. Averaged over 200 posterior draws, it gives P(next answer is a hallucination) with an uncertainty band.

3

Pre-emptive action (optional)

If the forecast exceeds the cost-based threshold 1/(1+10), the guard can add a re-grounding reminder. Experiments showed this mostly adds unwarranted UNKNOWNs, so monitor-only is the recommended setting.

4

Measure the answer

Three signals: mean token log-probability (confidence), top-20 entropy (hesitation) and lexical grounding (overlap with a chart row).

5

Bayesian filter

The state probabilities over Grounded / Uncertain / Hallucinating are updated causally: prior from the previous turn × likelihood of these features. The result uses only answers given so far, never the future.

6

Hold or commit, then check

If P(H) exceeds the threshold, the answer is held for pharmacist verification instead of being written to the reconciliation list. The gold grade, which the guard never sees, shows whether the decision was right.

Reading the labels

G · grounded correct code, or UNKNOWN when the row truly is missing   U · uncertain UNKNOWN although the row exists   H · hallucination a wrong-patient, wrong-field or invented code, or any code for a missing row.

All patients, names and codes are fictional. This is a research prototype, not a medical device.
